## Exact files and reproduction

- `manifest.json`: all nine PBR downloads and HDR, exact URLs, bytes, supplier MD5 checksums and date.
- `pine-manifest.json`: both needle atlas downloads, same fields.
- `*-info.json` / `*-files.json`: individual supplier metadata, authors and acquisition inputs.
- `vehicles/manifest.json`: original source/runtime vehicle GLB sizes and LOD group names.

Diffuse maps are sRGB; normal/ARM are linear. Normal/ARM WebP is lossless. ARM's green channel supplies roughness; metallic/AO are not indiscriminately applied to dielectric roads. CC0 allows commercial use, modifications and redistribution, including web assets/source repositories.

Run `scripts/remaster-assets.mjs` / `scripts/remaster-pine.mjs` with a directory containing Sharp; finite downloads are checksum-verified. `node scripts/bake-remaster-vehicles.mjs` bakes actual authoring geometry, preserves semantic material/attachment names, welds and Meshopt-compresses runtime GLBs. Runtime needs neither Sharp nor internet. Blender is optional for this checkpoint.

Vehicles, accessories, original trunks/placement, rocks, architecture additions, skeletons, animation clips and shaders are project-authored. Embedded drivers retain Quaternius provenance. No blanket public license is asserted for original work or branding. Existing Novarah / Novarah Technologies and supplied-logo ownership terms remain in `ASSET_CREDITS.md`.
